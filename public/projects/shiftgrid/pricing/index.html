DEPLOYMENT QUESTIONS

The details
before the model.

What does “per facility” mean?

A facility is one operational location with its warehouse and yard model. Operator includes up to 25 connected vehicles per facility. Network is intended for shared multi-site topology and a custom fleet.

Can we compare plans before deployment?

Yes. Select any tier above to highlight its capability column. The available features, administrative scope and integration depth are explicit.

Are these purchasable subscriptions?

No. SHIFTGRID is fictional portfolio software. These prices illustrate a deployment model; there is no checkout, payment or subscription on this site.

What is included in Operator?

Interactive warehouse and yard coordination, 25 vehicle views, ten example rule workflows, API and connector configuration, scoped operator roles and assisted deployment guidance.

How would an existing stack connect?

Start with system ownership, stable entity IDs and required event cadence. A real deployment would scope connectors and permissions before connecting a WMS, TMS, ERP or telematics source.

What are the deployment requirements?

Facility geometry, source-system entity references, arrival windows and operational roles form the initial model. A production integration and security review would follow. No infrastructure or implementation fees are being sold by this concept.
